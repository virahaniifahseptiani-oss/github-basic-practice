# GitHub Basic Practice
## About
Repository ini digunakan untuk mempelajari penggunaan dasar
GitHub melalui browser.
## Learning Goals
- Create and organize a repository.
- Upload and edit files.
- Write documentation using Markdown.
- Review commit history.
- Practice branches and pull requests.
## Repository Contents
- `README.md`: Penjelasan utama repository.
- `introduction.txt`: File latihan upload.
- `notes/learning-notes.md`: Catatan pembelajaran.
## Tools
- GitHub
- Web browser
- Text editor
## How to Use
1. Baca README untuk memahami tujuan repository.
2. Buka `introduction.txt` untuk melihat file latihan.
3. Buka `notes/learning-notes.md` untuk membaca catatan.
